

# Python Freelancing Project Day03

## Project Description

This is a Python-based File Organizer that automatically organizes files into different folders based on their file types.
This is a Python Project Created as a part of my 30-Day Python Freelancing Roadmap.

## Features

- Automatically organizes files
- Sorts files by file type
- Creates folders when needed
- Supports common file extensions
- Simple and easy to use
- Built with Python

## Requirements

- Python 3.x
- Git
- VS Code

## How to Run

1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Run the Python file.


## Example Usage
 Run the Following Command in the Terminal

```bash
python file_organizer.py
```
